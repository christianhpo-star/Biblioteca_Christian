# Projeto

- Repositório: `christianhpo-star/Biblioteca_Christian`.
- Responsável: Christian Oliveira.
- Público: pesquisador que organiza leituras digitais e físicas e produz fichamentos para consulta.
- Tarefa principal: localizar uma obra, ler, registrar ideias e citações com página, recuperar o conteúdo escrito e exportar um fichamento completo.
- Stack preservada: HTML, CSS, JavaScript clássico, módulos de sincronização Firebase e esbuild para os pequenos bundles de integração. Node.js para ferramentas locais e Playwright para regressão no navegador.
- Marca institucional: não declarada. Nenhum token do Contrapelo foi presumido homologado.
- Escopo autorizado em 06/11/2026: publicar o código no GitHub e modularizar, permitindo revisar versões antes de alterar a cópia principal.
- Fora deste envio: deploy, merge, migração de produção, mudança de autenticação/banco, PDFs e fichamentos pessoais, nova integração de escrita no Drive.
- Instalação, comandos e fluxo de revisão: `README.md`.
